# WHAT THIS FILE IS
#   The rename plan for `@oh-my-pi/*` → the new npm scope, in two sections that
#   must never be confused with each other:
#
#     1. SCOPE IDENTIFIERS — package.json manifests that MUST be rewritten.
#     2. WIRE / OPS IDENTITY — bare "oh-my-pi" strings that MUST NOT be
#        rewritten, each with the reason it is load-bearing.
#
#   The filename says "keep-list" because section 2 is the part a reviewer
#   actually has to keep: section 1 is a mechanical list that a rename pass
#   consumes, while section 2 is the set of things a rename pass must leave
#   alone. Do not read section 1 as "also keep these".
#
# HOW SECTION 1 WAS GENERATED (regenerate with exactly this, do not hand-edit)
#   git grep -l "@oh-my-pi/" -- 'packages/*/package.json' > /tmp/manifests.txt
#   Regenerated 2026-10-01 at commit 1afdc3cebb: 24 manifests.
#
# DRIFT CONSTRAINT — a gate must compare this list against that command and fail
#   when they differ. A keep-list written by hand decays SILENTLY: each new
#   package that forgets to be added is skipped by the rename with no error and
#   no way to notice afterwards. "23" above is a claim that goes stale the
#   moment a package is added or removed, which is exactly why it is written
#   down rather than left implicit.
#

# 2. WIRE / OPS IDENTITY — DO NOT REWRITE
# ---------------------------------------------------------------------------
# A rename pass rewrites `@oh-my-pi`, so it cannot reach these: they are the
# bare string "oh-my-pi" with no `@`. That is fortunate, because all of them are
# places where changing the value is wrong, silently, and not undoable.
#
# The repo already has the right pattern for most of this: `WIRE_NAME` in
# `@oh-my-pi/pi-utils` is the single named constant for the wire identity, used
# at ~14 call sites (dap/session.ts, blob-broker/uploaders-legacy.ts,
# hindsight/bank.ts, modes/acp/acp-agent.ts, …). The entries below are the ones
# that do NOT follow it.
#
# Measured 2026-10-01 at commit 8c76ef6cb2 with:
#   git grep -nE '(^|[^@a-zA-Z0-9_-])"oh-my-pi"' -- 'packages/*/src/*.ts' 'packages/*/src/**/*.ts'
# 7 occurrences across 6 files. Disposition per line:
#
# GOTCHA, verified by measurement, that a future gate must not repeat: the
# single-glob form `-- 'packages/*/src/**/*.ts'` reports only 5 of the 6 files.
# git's `**` does not match ZERO directory levels, so a .ts sitting directly in
# src/ is skipped — and the file it skips is
# telemetry-export-otlp.ts, a wire identity. A gate written with the short glob
# would report the inventory as complete while silently omitting the one entry
# that must never be renamed. `git grep` also only sees TRACKED files, so a
# peer's untracked new file is invisible to it too; both facts make this
# command's output a lower bound, not a complete list.
#
#   packages/ai/src/registry/oauth/zai.ts:25
